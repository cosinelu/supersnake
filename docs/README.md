# 消食蛇 · 工程文档

本目录是在线联机功能（v3.0）的设计与计划文档。所有联机相关开发以这里的设计为准；
玩法/数值调参仍以 `js/config.js` 与根目录 `README.md` 为准。

## 目录约定

```
docs/
  README.md                        ← 本文件（文档索引）
  architecture/
    01-online-multiplayer.md       ← 联机对战架构设计（同步模型 / 协议 / 模块拆分 / 部署）
  plan/
    01-online-mvp-plan.md          ← 任务拆分与里程碑计划（M0~M6，含验收标准）
```

## 约定

- 架构决策变更时，先改 `architecture/` 文档，再动代码；文档与代码冲突以文档为讨论起点。
- 计划文档中的任务状态用 `[ ]` / `[x]` 维护，完成即勾。
- 文档一律中文，协议字段/代码标识符一律英文。
