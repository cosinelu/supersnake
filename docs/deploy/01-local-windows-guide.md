# 消食蛇联机版 · 本地部署与试玩教程（Windows）

> 读者：执行本教程的 AI 助手（最终用户是小白，请代他操作并解释）。
> 目标：在一台 Windows 机器上跑起联机服务器，用浏览器玩「在线对战」。
> 特点：**零编译、零构建**——纯原生 JS，下载即跑，全程只需 Node.js。

---

## 第 0 步：检查 Node.js（1 分钟）

打开 cmd 或 PowerShell，执行：

```cmd
node -v
```

- 显示 `v18.x` 或更高（如 `v22.x`）→ 通过，继续。
- 提示「不是内部或外部命令」→ 先装 Node.js：到 https://nodejs.org 下载 LTS 版，一路下一步即可，装完**重开**一个命令行窗口再验证。

## 第 1 步：获取项目代码

二选一：

```cmd
:: 方式 A：git 克隆（推荐）
git clone git@github.com:cosinelu/supersnake.git
cd supersnake

:: 方式 B：下载 ZIP 解压后，进入解压目录
cd /d C:\Users\<用户名>\Downloads\supersnake-main
```

后续所有命令都在项目根目录（能看到 `index.html`、`server\`、`js\` 的那层）执行。

## 第 2 步：安装服务器依赖（只此一次）

```cmd
cd server
npm install
cd ..
```

预期输出：`added N packages`（只有 `ws` 一个依赖，几秒装完）。
若 `npm` 报「不是命令」，同第 0 步，重装 Node 或重开窗口。

## 第 3 步：启动服务器

**本机自己玩（推荐先这样验证）：**

```cmd
node server\index.js
```

看到这一行就是成功，**保持窗口开着**：

```
[supersnake] online server listening on 127.0.0.1:8090
```

**局域网多人一起玩（手机/其他电脑也要连）：**

```cmd
:: cmd：
set HOST=0.0.0.0 && node server\index.js
```

```powershell
# PowerShell：
$env:HOST='0.0.0.0'; node server/index.js
```

然后在 Windows 防火墙弹窗里点「允许访问」；其他设备浏览器开 `http://<本机局域网IP>:8090/`
（IP 用 `ipconfig` 查「IPv4 地址」，如 `192.168.1.50`）。

## 第 4 步：打开游戏

浏览器（Chrome/Edge）地址栏输入：

```
http://127.0.0.1:8090/
```

看到「消食蛇」主菜单即成功。页面和联机通道同一个端口，**无需任何额外配置**。

## 第 5 步：玩在线对战

1. 点主菜单的「**在线对战**」→ 进入匹配等待页；
2. 匹配规则：**满 4 名真人立即开局**；不够 4 人时**等 20 秒由 AI 补位**开局（所以一个人也能玩）；
3. 想双人验证：再开一个浏览器标签（或另一台设备开同一地址），两边都点「在线对战」，等待页会显示「已就位 2/4」，20 秒后一起进图；
4. 操作：鼠标/手指拖动左下角摇杆控制方向；活到最后或总分最高者胜；
5. **规则提醒：掉线直接判负，不支持重连**（关掉标签 = 当场死亡，对面看到尸体掉落）。

单机三模式（闯关/无尽/多人对战-本地AI）不依赖服务器，随时可玩。

## 第 6 步：停止服务器

在服务器窗口按 `Ctrl + C`。

## 故障排查

| 现象 | 原因与处理 |
|---|---|
| 启动报错 `EADDRINUSE ... 8090` | 端口被占用（多半已有一个服务器在跑）。先 `netstat -ano \| findstr :8090` 找到 PID，再 `taskkill /PID <PID> /F`，然后重启 |
| 浏览器打不开页面 | ① 确认服务器窗口还在且没报错；② 地址必须是 `http://127.0.0.1:8090/`（带 http://）；③ 不要直接双击 `index.html`——虽然单机模式能玩，但那不是本教程的联机路径 |
| 局域网设备连不上 | ① 第 3 步必须设 `HOST=0.0.0.0`；② 检查 Windows 防火墙入站是否放行 8090；③ 两台设备须在同一个 Wi-Fi/网段 |
| 点「在线对战」一直转圈 | 服务器没启动或没连上：看服务器窗口是否有报错；浏览器 F12 控制台看 ws 连接错误 |
| 两人都在匹配但没开局 | 正常：满 4 人才立即开，2 人要等 20 秒 AI 补位 |

## 给 AI 的验收清单（逐项确认后再交付给用户）

- [ ] `node -v` ≥ 18
- [ ] `npm install` 在 `server/` 下成功
- [ ] 服务器启动并输出 `listening on ...:8090`
- [ ] `curl http://127.0.0.1:8090/` 返回 HTML（或浏览器能打开）
- [ ] 浏览器主菜单出现「在线对战」按钮
- [ ] 双标签匹配能显示「已就位 2/4」并进入同一对局（互相能看到对方蛇和名牌）
- [ ] 关掉一个标签，另一台在 1~2 秒内看到对方死亡并进入结算
