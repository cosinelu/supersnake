# 游戏设计：模式、规则与数值

> 读者：人类玩家/策划 + AI Agent。
> 本文是**玩法规则的唯一权威描述**；所有数值的真源是 `js/config.js`（逐项有注释），
> 本文只写规则与语义，改动数值请去 config.js 并同步本文对应描述。
> 联机实现细节（协议/同步模型）见 `docs/architecture/01-online-multiplayer.md`。

---

## 1. 一句话玩法

贪吃蛇的走位 + 祖玛（Zuma）的消除：自由方向游动，吃到色块**从头部插入**蛇身，
凑齐 **4 个相邻同色节**即消除得分。撞墙/撞蛇即死。尾巴永远有 1 节消不掉的「尾巴节」。

美术：蜡笔手绘风（纸色底 + 深色描边），8 色蜡笔调色板。

## 2. 四个模式的区别（核心速查表）

| | 闯关模式 | 无尽模式 | AI对战（本地） | 在线对战（联机） |
|---|---|---|---|---|
| 入口按钮 | 「闯关模式」 | 「无尽模式」 | 「AI对战」 | 「在线对战」 |
| 对手 | 无 | 无 | 3~14 条 AI 蛇（动态增长） | 2~4 名真人 + AI 补位 |
| 地图 | 随关递增（L1 1500×1000 → L10 4800×3200） | 3600×2400 | 4200×2800 | 4200×2800（同 AI对战） |
| 目标 | 达到本关目标分 → 过关，共 10 关 | 活下去刷最高分 | 活到最后 / 刷最高分 | 活到最后（≤1 名真人存活）或 5 分钟到时按总分 |
| 彩色星道具 | 不出现 | 不出现 | **出现**（+20% 总分抢夺） | **出现**（同左） |
| 需要服务器 | 否 | 否 | 否 | **是**（服务器权威模拟） |
| 结算依据 | 过关/撞死 | 最高分 | 名次 + 淘汰/击杀统计 | 名次 + 掉线判负 |
| 代码入口 | `game.js startLevel` | `game.js startEndless` | `game.js startMulti` → `multiplayer.js`（本地编排） | `game.js startOnline` → `net/onlineMatch.js`（客户端）+ `server/`（权威端） |

> 历史说明：「AI对战」在 v3.0 之前叫「多人对战」（容易和在线对战混淆，故改名）。
> 代码内部模式标识仍为 `multi`；`game.online` 非空表示该局是联机局。

## 3. 通用规则（四模式共享）

### 3.1 移动与碰撞
- 自由方向连续移动（非网格），转向速率上限 `TURN_RATE`；速度 = 基础 + 长度加成（每节 +2.5px/s），无尽模式另随时间提速。
- **撞墙/撞边界 → 立即死亡**；撞到自己身体不致死（见 3.4 自吃重组）。
- 边界墙 44px 纯视觉加厚；地图内每隔 9 秒动态新增一段障碍墙（避开所有活蛇，上限 28 段）。

### 3.2 吃色与消除
- 吃普通色块：该颜色一节**插入蛇头**（祖玛式一端推入）。
- **相邻同色 ≥4 节 → 消除**，基础分 = 节数 × `ELIM_SCORE`(10)。
- **连锁**：一次消除后新相邻的同色段 ≥4 会连续触发，分数 ×连锁层数。
- **连击**：2400ms 窗口内连续触发消除，倍率逐次 +1，封顶 ×5。
- **万能色节**（白底星标）：通配任意颜色，可桥接不同色段凑连。
- **消除保底**：消除会导致颜色节不足 3 节时，改为整段消除 + 随机补 4 块已解锁颜色砖继续。

### 3.3 尾巴节
- 每条蛇末尾恒有 1 节深色小尾鳍：**不参与消除判定、不会被消除/咬断移除、不占保底计数**。出生 = 5 颜色节 + 1 尾巴节 = 总长 6。

### 3.4 自吃重组
- 蛇头碰到**自己**身体时：从身体咬下一节补到头部（总长不变），制造凑连机会；冷却 380ms。

### 3.5 颜色解锁
- 调色板 8 色（红蓝绿橙紫黄青粉），开局解锁前 4 色。
- 闯关：每 2 关 +1 色（L9 起 8 色全解）；无尽：每存活 45 秒 +1 色；多人/联机：同无尽节奏。

### 3.6 计分
```
总分 = 存活分（1 分/秒） + 消除分（ELIM_SCORE × 连锁 × 连击 + 道具附加分） + 彩色星加成（多人局）
```

## 4. AI对战（本地）细则

- **编制**：开局 3 条 AI，每存活 25 秒 +1 条，封顶 14 条；AI 被淘汰后 3~5 秒重生补编。
- **AI 决策**（`js/ai.js`，加权转向）：每帧评估 24 个候选方向 = 寻食吸引（偏好同色/凑连）− 撞墙/撞蛇/自卷/头对头惩罚 + 惯性 + 游走噪声。
- **性格差异**：每条 AI 有随机速度档（130~170px/s）与性格参数（贪食/谨慎）；早期 AI 莽/怂差异大，后期（智力随时间 0→1 渐变）更均衡聪明。
- **咬断机制**：头撞其他蛇身体 → 撞者死亡，被撞者被咬掉「离撞者头最近的一节」；被咬后不足 3 节 → 直接淘汰并计撞者 1 击杀。头对头相撞 → 双双淘汰。
- **尸体掉落**：死蛇每隔 2 节掉 1 个色块（≈50% 的节）+ 必掉 1 个随机道具（每 10 节再 +1 个）。
- **彩色星**：见 §5 道具表，仅多人/联机出现。
- **HUD**：右侧实时排行榜（按节数降序），头顶昵称标签（玩家为「我」，AI 从昵称池取不重复的名字）。

## 5. 在线对战（联机）细则

与 AI对战同地图同规则，差异全部来自「服务器权威 + 真人对手」：

### 5.1 匹配
- 队列满 4 名真人立即开局；队首等待超 20 秒且 ≥1 名真人 → 以现有真人 + AI 补位开局（**一个人也能开局**）。
- 匹配中可取消；开局倒计时 3 秒。

### 5.2 权威模型（客户端不可信）
- 服务器 30Hz 固定步长模拟，15Hz 广播快照；客户端只上行转向输入（30Hz 节流）。
- 本机蛇 = 客户端预测 + 快照软校正；他机蛇 = 120ms 插值。
- **掉线 = 判负**，不支持重连；本人死亡立即收到结算（对手继续）。

### 5.3 结算
- 多真人局：存活真人 ≤1 → 存活者胜；单真人局：本人死亡 → 结算（AI 存活不影响）。
- 或 5 分钟对局上限到时 → 按总分排名。
- 排行榜：存活优先，其后按总分降序。

### 5.4 昵称规则
- 昵称存于 localStorage `crayon_snake_web_nick`；首次缺省生成「我+4 位随机数」，最长 12 字。
- **同局真人昵称由服务器去重**：同名依次追加 `·2` `·3`（超长先截断基部）——同一浏览器多标签页共享 localStorage 时昵称必然相同，靠服务器去重保证名牌可区分（`server/matchmaker.js _dedupeNames`）。
- **AI 不与真人撞名**：真人昵称注册进 `usedNames`，AI 取名避让；真人淘汰后其名字整局保留（`js/multiplayer.js addPlayer/kill`）。
- 回归测试：`test/net/nick.test.js`。

## 6. 道具系统

稀有度 4 档（边框：彩虹金 > 橙 > 紫 > 蓝）。特殊道具出现概率随存活时间从 12% 线性爬到 42%（180 秒到顶）。

| 道具 | 稀有度 | 效果 | 备注 |
|---|---|---|---|
| 彩色星 | 彩色·抢夺 | 玩家吃到：当前总分立即 +20%（可叠加）；AI 吃到只消耗不加分 | **仅多人/联机**；开局 18s 首现，场上最多 1 颗，被吃/42s 超时后 32s 再现；全屏播报 + 小地图涟漪，AI 高优先抢 |
| 万能色 | 强 | 通配任意颜色，桥接不同色段凑 4 连 | |
| 炸弹 | 强 | 清除蛇身所有 ≥2 节的连续同色段 | 每节额外 +8 分 |
| 消色 | 强 | 消除蛇身全部指定颜色节（不管位置/连续性） | 每节额外 +6 分 |
| 流星砖块 | 中 | 从地图边缘直线飞入，命中蛇身把该色注入中段 | 每 6.5s 一颗，同屏 ≤3 |
| 后三消色 | 中 | 只消除指定颜色最靠尾的 3 节 | 每节额外 +5 分 |
| 随机消 3 | 中 | 随机移除 3 节 | |
| 减速 | 弱 | 4 秒内速度 ×0.6 | 防御型喘息 |
| 随机消 1 / 2 | 弱 | 随机移除 1 / 2 节 | |
| 普通色块 | 无 | 头部插入 1 节该颜色 | 基础食物 |

刷新权重与全部参数见 `js/config.js`（`ITEM_WEIGHTS` / `GRAB_*` / `METEOR_*`）。
