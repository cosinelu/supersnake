## 怎么玩

**直接双击 `index.html` 即可游玩**（支持 `file://` 协议直开，无需起服务器）。
也可以 `python3 -m http.server` 后访问，效果相同。

- **桌面端**：方向键 / WASD 控制转向（支持组合键 8 方向，如 W+D = 右上）；
  也可以鼠标按住左下角摇杆拖动，**拖动方向即目标方向**（自由角度，不量化）。
- **触屏端**：按住左下角虚拟摇杆拖动（向量方向即目标角，带死区）。
- 蛇头会以**最大转向速率**平滑转向你指的方向，松开输入则保持当前方向直行。
- 建议横屏体验（竖屏也能玩，顶部会有提示条）。

### 规则

- **自由方向贪食蛇**：蛇头连续移动、恒速前进；身体沿蛇头轨迹按固定弧长间距跟随。
  不做蛇身自碰；撞到世界边界或内部灰墙立即结束。
- **节清晰可辨**：节间距 30px = 节直径 26px + 4px 纸色间隙，节描边加粗到 3px 深色，
  相邻节不重叠，连续同色有几节一眼能数清（消除游戏的核心可读性）。
- **吃色补头**：吃到或身体压到色块，该颜色 `unshift` 进头部——头立即变成新颜色，
  原头变成第 1 节身体，总长 +1（凑 4 连主要发生在头附近，这正是设计意图）。
- **尾巴节（v2.3）**：颜色序列 `colors` 保持纯颜色节，身体几何总长 = 颜色节数 + 1，
  末尾恒多 1 节「尾巴节」——画成深色（#3A3238）蜡笔小尾鳍/圆锥（蝌蚪尾巴），一眼认出"这节消不掉"。
  它不参与颜色序列的消除判定（等效于在序列末尾但不凑连）、不会被消除或咬断移除、
  不占「保底 3 节」计数；但它是身体的一部分：收集色块、撞墙/被撞判定对它正常生效
  （别人头撞上尾巴照样算撞身体）。因此全消除极限情况下蛇至少剩 尾巴 + 3 颜色节 = 4 节。
- **相邻 ≥4 连同色立即消除**：长度保底 3 节（只计颜色节），带蜡笔屑 + 星形闪光特效。
  **连锁倍率计分**：消除后颜色接拢又凑成 ≥4 连则连锁升级（chain+1），
  第 chain 次消除每节得分 = 5 × chain（chain1=+5、chain2=+10、chain3=+15…）；
  特效逐级放大（粒子数/星形大小 ×1.6、×2.2…），chain≥2 时在消除点弹手绘风「N连锁！」文字。
- 计分 = 存活秒数（1 秒 1 分）+ 消除分。
- **局内动态加速**（只改速度，几何判定不变）：
  闯关 速度 = 关卡基础 + 1.2×当前节数 + 0.5×存活秒，封顶 基础+120；
  无尽 保留时间提速（+1.5 px/s²）再叠加 1.2×节数，封顶 340 px/s。
- **世界大地图**：闯关 L1 ≈ 2400x1600 → L10 ≈ 5200x3600 世界像素；无尽 3600x2400。
  相机平滑跟随蛇头并钳制在世界内；右侧 HUD 有**小地图**（世界边界/墙/色块/视口框/蛇头亮点）。
- **边界即墙**：世界四周是与内部墙一致的蜡笔排线墙带（灰底+斜线排线+深色描边，厚 30px），
  小地图边界同步画成墙样式；撞界判定不变（碰到即死）。
- 色块每 4 秒稀疏补足（目标数 = 世界面积/90000，夹取 [8,40]；拒绝采样：距已有色块 ≥140px、
  离蛇 ≥80px、不压墙、最多试 50 次），未吃掉的保留。
- **颜色解锁**：8 色蜡笔调色板，初始 4 色（红蓝绿橙）；闯关每 2 关 +1 色，无尽每存活 45 秒 +1 色，
  封顶 8 色；新颜色解锁时弹**无底板**手绘提示（深色描边文字 + 新色小色块，浮于视口上方 1/4 处）1.5 秒。
- **闯关模式**：10 关，世界尺寸/墙段/基础速度递增，目标分 60→240；进度存 localStorage，主菜单可选关。
- **无尽模式**：速度随时间与长度提升（封顶 340 px/s），最高分存 localStorage。

### 多人对战（v2.1）

- **入口**：主菜单第三个选项「多人对战」，进入 4200x2800 共享大地图（`MULTI` 可调）。
- **场上构成**：恒定维持 **玩家 1 名 + 6 条 AI 蛇**（`MP_AI_COUNT`）。每条蛇独立实例：
  自己的颜色序列 / 轨迹 / 速度档位 / 计分，复用同一个 Snake 类与蜡笔渲染。
  AI 有随机中文昵称（14 个名字池，场上不重复）、基础速度 130~170 px/s 随机、
  性格参数 **greed（贪食 0.6~1.4）/ caution（谨慎 0.6~1.4）** 驱动行为差异。
- **AI 行为**：每帧在 16 个候选方向上加权打分取最优——① 寻食（方向对齐 × 距离衰减，
  偏好与头部同色的色块）；② 避墙（近 ≈1 身位 / 远 ≈2 身位两个前景点探测，近点重罚、远点轻罚）；
  ③ 避蛇（前景点附近出现其他蛇身体节则避让）；④ 惯性 + 小幅随机游走。
  **AI 只输出目标角，转向速率与玩家一样受 TURN_RATE 钳制**，公平。
- **淘汰**：头撞墙/边界 → 淘汰；**头撞其他蛇身体节 → 淘汰**（身体主人记 1 击杀）；
  **头对头相撞 → 两条都淘汰**（不记击杀，简单公平）。不做蛇身自碰（沿用现有设计）。
- **咬断机制（v2.2）**：A 头撞 B 身体时，B（被撞者）**被咬中的那一节也短掉**——
  被咬节 = B 身体**颜色节**（不含头、不含尾巴节）中离 A 头心最近者，从颜色序列移除后
  身体由轨迹自然收拢；只撞上尾巴节时撞者照样淘汰，但不产生咬断（尾巴节咬不掉）；
  **保底**：被咬后 B 节数 < 3 → B 直接淘汰（尸体照常掉落，计入 A 的击杀）；
  **消除联动**：被咬移除后颜色接拢凑成 ≥4 连同色 → 正常触发消除（连锁/倍率计分照常，
  分数与「累计消除方块」都记 B）；被咬处迸小粒子 + B 短暂闪白/抖动 0.3 秒。
  AI 与玩家一视同仁（AI 咬玩家、玩家咬 AI、AI 互咬都生效）。
- **尸体掉落**：被淘汰的蛇按节在原地散落成色块（每隔 2 节掉 1 个、起点随机 ≈50% 的节），
  供其他蛇捡食——多人模式的主要资源循环。
- **补充**：AI 淘汰后延迟 3~5 秒在世界边缘、远离其他蛇的安全位置重生
  （初始 5 颜色节 + 1 尾巴节 = 6 节总长），维持 6 条 AI 编制；玩家淘汰不重生，进结算。
- **玩家体验**：相机始终跟随玩家；小地图显示所有蛇亮点（AI 用各自头部颜色、玩家金色高亮）；
  右侧 HUD 实时排行榜（按当前节数降序，玩家加粗高亮）；头顶昵称小手绘标签（深色描边无底板，
  玩家为「我」）。
- **结算（v2.2 美化）**：手绘风卡片底板（抖动描边圆角 + 纸张噪点），标题按名次变化
  （第 1 名「冠军！」+ 皇冠/星星涂鸦，2~3 名「很棒！」，其余「再接再厉」）；
  **每行一项**：排名 / 存活时间 / 总分 / 时间分 / 消除分 / **累计消除方块**（本局消除
  移除的总节数，含连锁与被咬触发）/ 击杀数 / 最终节数——左侧涂鸦小图标 + 标签 +
  右侧醒目数值；卡片淡入 + 各行依次 ~80ms 滑入；按钮（再来一局 / 返回菜单）手绘风加粗。
  最佳成绩（最长节数 + 最高分）存 localStorage 新 key `crayon_snake_web_mp_best`。
- **一致性**：消除特效 / 连锁文字 / 颜色解锁（按存活时间，规则同无尽）全部复用；
  排线边界墙 + 6 段内部墙（比无尽略少）；色块稀疏刷新密度提高
  （目标数 = 面积/70000，夹取 [10,50]，7 条蛇在吃）。

## 工程结构

```
index.html      内联 CSS + 按依赖顺序的 <script> 标签（无 ES Module，file:// 直开）
js/config.js    调色板、全部数值参数、解锁规则纯函数、多人/AI 参数   ★调参只改这里
js/utils.js     确定性伪随机 hash2、clamp、角度归一化/转向逼近
js/storage.js   localStorage 封装（JSON 容错 + 内存降级）
js/levels.js    10 关曲线：世界尺寸/墙段/目标分/蛇速（纯函数）
js/walls.js     世界边界 + 内部墙生成（一字/L/2x2 矩形组合，≤8% 面积，安全区）
js/snake.js     连续移动/转向速率钳制/trail-following/头部插入生长/4 连消除连锁保底（带连锁等级标记）/
                咬断移除节（removeSegAt，颜色序列去项、身体由轨迹收拢）/
                尾巴节（几何恒多 1 节：totalLength = colors+1，不可消除/不可咬断）
js/spawner.js   世界坐标稀疏刷新（只刷已解锁色；多人模式避让所有活蛇）
js/particles.js 蜡笔屑 + 星形闪光（连锁逐级放大）+ 「N连锁！」文字
js/ai.js        多人 AI 加权转向决策（寻食/避墙/避蛇/惯性游走，性格参数化）
js/multiplayer.js 多人对战编排：蛇管理/淘汰（墙·头身·头头）/咬断（保底淘汰·消除联动）/
                尸体掉落/AI 补充/排行榜/击杀/累计消除方块
js/renderer.js  蜡笔风渲染：纸张噪点、相机变换、抖动描边、排线边界墙、HUD 面板、排行榜、
                小地图（多蛇亮点）、AI 蛇与昵称标签、摇杆、被咬闪白抖动、多人结算卡片、
                尾巴节深色小尾鳍（drawTail）
js/joystick.js  固定底座摇杆（触屏+鼠标，自由角度）+ 键盘（8 方向组合）
js/game.js      状态机/连锁倍率计分/动态速度/关卡流/解锁/相机跟随钳制/横版布局/多人接入
js/main.js      启动、DPR 适配、resize、RAF 主循环
test/smoke.js   node 逻辑冒烟验证（121 项断言，含多人 3000 帧模拟、咬断机制与尾巴节规则）
```

所有 JS 均为 IIFE 挂 `window.CS` 全局命名空间；逻辑模块（config/utils/storage/levels/walls/snake/spawner/particles/ai/multiplayer/game）不依赖 DOM，可在 node 中直接加载。
